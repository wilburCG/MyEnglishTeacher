# MyEnglishTeacher

AI 英语私教 App —— 覆盖初中 / 高中 / 大学阶段，按学段分级、按主题学习。

## 两大核心功能

1. **词句输入**：背单词（SRS 间隔重复）、典型句型库、精选影视剧台词
2. **输出训练**：AI 虚拟老师场景化模拟对话，实时纠错讲解；专项听写练习，错误自动入复习闭环
