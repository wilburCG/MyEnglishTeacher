# MyEnglishTeacher 产品与技术设计（v0.2 已确认）

> AI 英语私教 App：覆盖初中 → 高中 → 大学，两大核心能力——**词句输入**（背单词 / 典型句型 / 影视剧台词）与**输出训练**（AI 虚拟老师对话纠错 + 专项听写）。
>
> 状态：**v0.2 决策已确认（2026-10-11），按里程碑开发中**。
>
> 已确认决策：① 移动优先 **PWA**；② GitHub 仓库 **public**；③ 内容打样从 **初一（junior-g7）** 起步；④ LLM 使用与 Mose 相同的**火山方舟 ARK（ark-code-latest）**账号与端点；⑤ 台词库以**《老友记 Friends》**为旗舰语料（短句精选 + 署名 + 审核制）；⑥ **AI 口语发音评分纳入 v1**（火山语音评测）；⑦ 先免费，限额日志表预留。

---

## 一、产品定位

- **一句话定位**：随身的 AI 英语私教，中学生到大学生都能用，按学段分级、按主题学习。
- **目标用户**：
  - 初中生（中考方向，CEFR A1–A2）
  - 高中生（高考方向，A2–B1）
  - 大学生（四级 / 六级 / 考研 / 雅思，B1–B2+）
- **核心学习闭环**：
  ```
  输入（背单词 + 句型 + 台词） → 输出（对话 + 听写）
          ↑                                        │
          └──── 错误自动入错词本，SRS 安排复习 ←──────┘
  ```
- **设计原则**：
  1. 能确定性完成的（判题、听写比对、排期）不交给 LLM，省成本、结果稳定可复现。
  2. LLM 只做它擅长的：开放对话、自然语言纠错讲解、内容生成（生成内容需过审/过校验）。
  3. 所有 AI 输出走**结构化 JSON + 后端校验**，判错宁漏勿滥（precision over recall），不误人子弟。

## 二、分级与主题体系

### 2.1 级别（level）

| level 编码 | 学段 | 词汇量参照 | 对标考试 | CEFR |
|---|---|---|---|---|
| `junior-g7` | **初一（打样起点）** | ~700 | 课内同步 | A1 |
| `junior` | 初中全段（初二/初三） | ~1,600 | 中考 | A1–A2 |
| `senior` | 高中 | ~3,500 | 高考 | A2–B1 |
| `cet4` | 大学 | ~4,500 | 四级 | B1 |
| `cet6` | 大学 | ~6,000 | 六级 / 考研 | B2 |
| `ielts` | 进阶 | 8,000+ | 雅思 / 托福 | B2+ |

用户注册时选当前级别，可随时切换；对话、词库、句型、台词全部按 level 过滤；老师用语难度跟随 level（受控词汇量 prompt）。

### 2.2 主题（theme）

首批约 12 个：校园生活、家庭与朋友、日常购物、餐厅点餐、旅行交通、健康运动、科技互联网、节日文化、情绪表达、观点议论、职场面试、商务沟通。

句型 / 台词 / 对话场景都带 theme 标签，支持「学完单词 → 在对应主题场景里用」。

**内容生产顺序**：M1 五个级别词表一次全量导入（ECDICT 带考试标签）；句型、场景、台词等需要人工/AI 生产的内容**先只做初一（junior-g7）打样**，闭环跑通后再向初二/初三及以上级别扩展。

## 三、功能模块设计

### 模块 A：词句输入（背单词 / 句型 / 台词）

#### A1. 背单词
- **学习模式**：单词卡正面（单词 + 音标 + 发音按钮），翻面（释义、例句、知识点）。
- **选词**：每个 level 对应词表（见 §六语料），按考纲顺序 + 词频排序；每天给新词 + 到期复习词（默认新词 15/天，可调）。
- **SRS 间隔重复**：简化 SM-2。用户自评「认识/模糊/不认识」，更新 ease factor、interval、到期日。
- **单词详情**：音标、词性、中文释义、英文释义、例句（可听）、同根词/常见搭配、（后续）真人发音。
- **音频**：初期用 edge-tts（免费、美/英音色）生成并缓存 mp3，不实时合成。

#### A2. 典型句型
- 结构化句型库：句型模板（如 `It takes sb. some time to do sth.`）+ 中文功能说明 + 语法点 + 3 个分级例句 + 可替换词槽。
- 学习方式：卡片讲解 → 跟读/造句练习（M3 后可让 AI 老师评判用户造句）。
- 按 level + 语法点（时态、从句、被动、虚拟语气…）+ theme 组织。

#### A3. 影视剧台词
- **旗舰语料：《老友记 Friends》**（日常口语密度高、语料干净、适合初中→大学分级精讲），数据模型按剧名/季/集/角色结构化，后续可扩其他剧。
- 字段：剧名（固定 Friends 起步）、季/集、说话角色、英文原句、中文翻译、难度 level、theme、语言点注释、音频。
- 学习方式：台词卡片（听 TTS → 理解 → 语言点讲解 → 跟读 + AI 发音评分）；可收藏。
- ⚠️ **版权处理**：只做**短句精选引用 + 出处署名（S01E01 / 角色名）**的学习用途；首批 100–200 条人工精选/AI 辅助后人工审核，后台支持投稿、审核后入库；**不提供整集剧本、不搬运原声/视频片段**（发音练习走 TTS/语音评测，不托管原声）。

### 模块 B：AI 模拟对话（虚拟老师）

- **场景驱动**：每个场景卡含 level、theme、老师人设、开场白、任务目标（如「点完一顿饭并结账」）、本场景推荐词汇。
- **老师行为**：
  - 全程英文，词汇难度受控于用户 level；用户卡壳时给提示（hint），可要求「用中文讲解」。
  - 每轮自然回应 + 推进对话，结尾抛一个 follow-up question。
- **纠错（核心）**：对用户每句话输出结构化标注：
  ```json
  {
    "has_error": true,
    "corrections": [
      {"original": "I go to school yesterday",
       "corrected": "I went to school yesterday",
       "kind": "tense",
       "explanation_zh": "yesterday 是过去时间，动词要用过去式 went。"}
    ],
    "teacher_reply": "Oh, what did you do at school yesterday?",
    "better_version": "I went to school yesterday and had a math test."
  }
  ```
  - 错误类型 kind：`grammar / tense / spelling / vocabulary / collocation / word_order / pragmatics`
  - 前端渲染：原句错误片段划线 → 显示修改建议 → 中文讲解卡；better_version 给「更地道的说法」（非错误，折叠展示，避免挫败感）。
  - **确定性兜底**：JSON schema 校验 + 一次重试；解析失败只展示老师对话，不崩；original==corrected 的条目直接丢弃；同一句最多展示 N 条，防止 LLM 过度批改。
- **对话报告**：结束后生成：总句数、错误数、错误类型分布、典型错句回顾、推荐复习词/句型（一键入错词本）、老师总评（中英双语，鼓励式）。

### 模块 C：专项听写

- **材料来源**：① 单词例句 ② 句型库例句 ③ 影视剧台词 ④ **本场对话中老师说过的句子**（个性化最有效）。按 level 过滤。
- **流程**：TTS 播放（常速 → 慢速 → 常速，可重听，计入提示次数）→ 用户逐句输入 → 提交。
- **判题（确定性引擎，不调 LLM）**：
  - 词级对齐（difflib / Levenshtein），错误自动分类：拼写错误 / 漏词 / 多词 / 词序 / 时态形态。
  - 大小写、标点、缩写（don't↔do not）做归一化；英式/美式拼写都算对。
  - 逐词标红标绿 + 得分（按实词/虚词加权）。
- **闭环**：错句、错词 → 错词本 + SRS 排期；同一条材料稍后重听，直到连续两次正确。
- 难度档位：单词听写（M1）→ 单句听写（M4）→ 段落听写（M4+）。

### 模块 D：学习系统（贯穿）

- 错词本 / 收藏本（单词、句型、台词统一收藏）。
- 每日目标 + 连续打卡 streak、学习时长、掌握度仪表盘。
- 个人词汇量增长曲线、错误类型雷达图（语法薄弱点可视化）。
- 对话/听写历史可回看。

## 四、AI Agent 与技术架构

### 4.1 后端架构

```
Client (Next.js PWA, mobile-first)
   │  HTTPS / SSE
Gateway (nginx)
   │
FastAPI backend
 ├── auth / users
 ├── vocabulary 模块（词库 + SRS 排期，纯确定性）
 ├── content 模块（句型 / 台词 CRUD + 审核）
 ├── conversation 模块
 │     ├── Agent 服务（调 LLM，SSE 流式）
 │     ├── correction parser（JSON 校验 + 兜底）
 │     └── report 生成
 ├── dictation 模块（TTS 取音频 + 确定性 diff 判题）
 └── progress 模块（统计 / 打卡）
Postgres 16（业务 + SRS 状态）
对象/本地卷：TTS 音频缓存
LLM：**火山方舟 ARK，模型与 Mose 当前相同（ark-code-latest / agent-plan 端点，复用现有账号 key）**；开发首步先验证该模型在英文对话/纠错 JSON 上的质量，若纠错结构化稳定性不足再评估同账号加挂 sibling 模型
TTS：edge-tts（零成本起步，缓存落盘）；后续可换火山 TTS
ASR / 口语评测：**火山引擎语音评测（AI 打分纠音，已确认纳入 v1 / M5）**，浏览器录音上传，按量计费并在 llm_call_log 同表记录费用
```

### 4.2 Agent 设计要点

- System prompt 组成：老师人设 + 用户 level（受控词汇表说明）+ 场景卡 + 当前对话摘要 + 严格输出协议。
- 一次调用同时产出「老师回复 + 纠错 JSON」（结构化输出 / function calling），回复走 SSE 流式，纠错部分随消息落库。
- 上下文管理：最近 N 轮全文 + 更早轮次滚动摘要，控制 token 成本。
- 成本护栏：每用户每日对话轮次数限额（默认 100 轮/天，可配置）；所有 LLM 调用写调用日志（token、成本）。
- 安全护栏：只谈英语学习相关；注入/越界请求礼貌拉回（沿用 WQD 项目的 guardrail 经验）。

### 4.3 技术栈（与现有项目一致，降低运维成本）

| 层 | 选型 |
|---|---|
| 后端 | Python 3.12 / FastAPI / SQLAlchemy 2 / Alembic / Pydantic v2 |
| 前端 | Next.js 14 + TypeScript + Tailwind CSS，**移动优先 + PWA**（可加桌面到手机，免上架先用起来） |
| DB | PostgreSQL 16 |
| 部署 | Docker Compose，复用现有阿里云 ECS；端口规划 met-* 容器 |
| LLM | 火山方舟 ARK doubao（plan 端点，与 WaterQualityDecoding 同账号） |
| CI | GitHub Actions（lint + pytest + 前端 build） |

## 五、数据模型（核心表，草案）

- `users`：账号（沿用手机号一键登录 + 邮箱管理员方案）、当前 level、每日新词目标。
- `word`：headword、phonetic、词性、释义（中/英）、例句、考试标签（zk/gk/cet4/…）、词频、音频路径。来源 ECDICT。
- `user_word_state`：user × word，SRS 状态（ease、interval、due_at、认识/模糊次数）、收藏标记。
- `word_review_log`：每次翻面记录（用于统计曲线）。
- `sentence_pattern`：level、theme、语法点、模板、例句 JSON、讲解。
- `movie_line`：剧名、季集、角色、英文、中文、level、theme、语言点、音频、审核状态。
- `scenario`：level、theme、标题、人设 prompt、开场白、任务、推荐词 JSON、状态。
- `conversation` / `conversation_message`：消息含 role、英文文本、老师回复等。
- `correction`：挂在 message 上，original/corrected/kind/explanation/better_version。
- `dictation_session` / `dictation_item`：材料来源类型+ID、用户答案、diff 结果 JSONB、得分、提示次数。
- `review_item`（统一错词本）：user、item 类型（word/pattern/line/sentence）、来源 ID、SRS 字段、错误次数。
- `llm_call_log`：场景、token、耗时、成本。
- `daily_stat`：打卡、学习分钟数（可由日志聚合，初期用物化视图/定时汇总）。

## 六、语料来源

- **词库**：[ECDICT](https://github.com/skywind3000/ECDICT)（开源 MIT），约 77 万词条，自带中考 `zk` / 高考 `gk` / 四级 `cet4` / 六级 `cet6` / 考研 `ky` / 雅思 `ielts` 标签、BNC/COCA 词频、柯林斯星级——一次导入即可分级，无需自己攒词表。初一（junior-g7）词表在 `zk` 范围内按**人教版七年级教材词表**筛出子集（~700 词），其余级别直接用 ECDICT 标签。
- **句型**：AI 辅助按语法点生成草稿 → 脚本校验英文例句（LLM 二次审 + 规则）→ 人工抽检；首批每 level 约 50 个高频句型。
- **台词**：人工精选 + 用户投稿审核制，见 A3 版权说明。
- **对话场景**：AI 生成场景卡草稿 → 人工审核上线，保证 level 难度准确。
